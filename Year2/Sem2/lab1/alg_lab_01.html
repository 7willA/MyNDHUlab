第一週：鏈結串列插入排序之深度解析

Week 1: In-depth Analysis of Linked List Insertion Sort

一、 演算法運作細節

1. Algorithmic Mechanics

插入排序在鏈結串列上的實作關鍵在於「指標重新導向」。其核心流程如下：

  1. 啞節點 (Dummy Node)： 創建一個輔助頭節點，將已排序的節點接在其後，可避免處理「插入位置在頭部」的邊界條件。
  2. 逐一掃描： 遍歷原始串列，對於每個節點 $P$，在已排序串列中從頭尋找第一個大於 $P.val$ 的位置。
  3. 指標操作： 將 $P$ 從原串列切斷，重新接合到新位置。

The key to Insertion Sort on a Linked List is "Pointer Redirection". The core flow is:

  1. Dummy Node: Create a helper head node. Append sorted nodes after it to avoid boundary cases for head insertions.
  2. Scan: Traverse the original list. For each node $P$, find the first position in the sorted part where the value is greater than $P.val$.
  3. Re-link: Disconnect $P$ from the original list and insert it into the new position by updating pointers.

二、 複雜度分析與推導

2. Complexity Derivation

分析指標Metric 複雜度Complexity 推導說明Derivation
時間 (Worst Case)Time (Worst Case) $O(n^2)$ 輸入為逆序時，第 $i$ 個元素需比較 $i$ 次。總和：$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$。 In reverse input, the $i$-th node requires $i$ comparisons. Total: $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$.

三、 演算法變形思考

3. Algorithm Variant

情境：假設使用雙向鏈結串列，並額外維護一個 tail 指向已排序部分的末尾。插入新節點 $X$ 時：
1. 若 $X.val \ge tail.val$，直接接在後方 ($O(1)$)。
2. 若 $X.val < tail.val$，則從 tail 向前搜尋位置。

Scenario: Use a Doubly Linked List with a tail pointer. When inserting $X$:
1. If $X.val \ge tail.val$, append it after tail ($O(1)$).
2. If $X.val < tail.val$, search backward from tail.
